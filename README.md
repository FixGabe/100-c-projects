# Projetos Praticos em C

Bem-vindo(a) ao meu repositório! Este projeto é uma jornada prática onde estou desenvolvendo programas praticos em C, evoluindo de algoritmos básicos de console até estruturas de dados avançadas, alocação dinâmica de memória e manipulação de arquivos.

# Objetivos
Consolidar fundamentos de lógica e sintaxe em C.
Dominar ponteiros, gestão de memória e manipulação de arquivos (`stdio.h`, `stdlib.h`, etc.).
Desenvolver o hábito de versionamento constante utilizando **Git e GitHub**.
Construir um portfólio prático e documentado.

# Tecnologias e Ferramentas
Linguagem: C (C99 / C11)
Compilador: GCC / Clang
IDE/Editor: VS Code
Controle de Versão: Git & GitHub
